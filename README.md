 # Volunteer Registration System

## Overview

This project is a simple Volunteer Registration System developed in Python using Behaviour Driven Development (BDD).

The system allows volunteers to register by providing a name and email address. Validation checks are included to ensure that required information is provided, email addresses are valid, and duplicate registrations are prevented.

## Features

* Volunteer registration
* Name validation
* Email validation
* Duplicate registration checking
* BDD testing using Behave

## Technologies Used

* Python 3
* Behave (BDD Framework)
* Git and GitHub

## BDD Scenarios

The system includes the following Behaviour Driven Development scenarios:

1. Successful volunteer registration
2. Missing email address
3. Duplicate volunteer registration
4. Invalid email format
